# 电竞陪玩护航系统 - 技术架构文档

## 概述

本文档详细描述电竞陪玩护航系统的技术架构设计，包括系统架构、技术栈选型、模块划分、分层设计、数据库设计、缓存策略、消息队列设计、存储方案、安全架构和部署架构等内容，旨在为开发团队提供完整的技术实现指导。

## 一、系统架构

### 1.1 整体架构设计

电竞陪玩护航系统采用前后端分离的分布式架构设计，前端使用Uniapp框架实现多端统一开发，后端基于ThinkPHP8.1框架构建RESTful API服务，消息通信采用Workerman实现WebSocket长连接，整体架构分为表现层、业务层、数据层和基础设施层四个大的层级。

系统整体架构采用微服务化的设计思想，将不同功能模块进行逻辑分离，通过API网关统一对外提供服务，前端应用支持小程序、H5、APP等多端展示，后端服务包括用户服务、商品服务、订单服务、支付服务、即时通讯服务等核心模块，基础设施层提供数据库、缓存、消息队列、对象存储等支撑服务。

### 1.2 技术架构特点

本系统技术架构设计遵循以下核心原则：高可用性设计确保系统7×24小时稳定运行，通过服务集群、负载均衡、故障转移等机制保障服务连续性；高性能设计通过缓存优化、异步处理、数据库读写分离等手段提升系统响应速度；可扩展性设计采用模块化架构，支持水平扩展和垂直扩展以应对业务增长；安全性设计从网络层、应用层、数据层多个维度构建安全防护体系；可维护性设计通过日志追踪、监控告警、配置中心等设施提升运维效率。

## 五、分层架构

### 5.1 经典三层架构

本系统采用经典的三层架构设计，包括控制器层（Controller）、服务层（Service）和模型层（Model），在三层架构基础上增加仓储层（Repository）实现数据访问的封装，提高代码的可维护性和可测试性。

#### 5.1.1 控制器层（Controller）

控制器层负责接收用户请求、参数校验、调用服务层处理业务逻辑、返回响应数据，控制器层不包含业务逻辑代码，仅做请求的转发和响应的封装。

```php
<?php

namespace app\api\controller;

use app\common\controller\BaseApiController;
use app\service\OrderService;
use think\response\Json;

/**
 * 订单控制器
 */
class Order extends BaseApiController
{
    protected OrderService $orderService;
    
    protected function initialize(): void
    {
        parent::initialize();
        $this->orderService = app(OrderService::class);
    }
    
    /**
     * 创建订单
     */
    public function create(): Json
    {
        // 参数获取
        $data = $this->request->post();
        
        // 调用服务层
        $result = $this->orderService->createOrder($this->userId, $data);
        
        if ($result === false) {
            return $this->error($this->orderService->getError());
        }
        
        return $this->success('订单创建成功', $result);
    }
    
    /**
     * 订单列表
     */
    public function list(): Json
    {
        $params = $this->request->param();
        $params['user_id'] = $this->userId;
        
        $list = $this->orderService->getOrderList($params);
        
        return $this->success('获取成功', $list);
    }
}
```

#### 5.1.2 服务层（Service）

服务层负责封装业务逻辑，处理业务规则、数据转换、事务控制等核心业务功能，服务层是业务逻辑的核心层，应该包含所有的业务处理代码。

```php
<?php

namespace app\service;

use app\model\Order as OrderModel;
use app\model\Product as ProductModel;
use app\model\User as UserModel;
use app\repository\OrderRepository;
use think\exception\ValidateException;

/**
 * 订单服务层
 */
class OrderService
{
    protected OrderRepository $repository;
    
    public function __construct()
    {
        $this->repository = new OrderRepository();
    }
    
    /**
     * 创建订单
     */
    public function createOrder(int $userId, array $data): array|false
    {
        // 数据验证
        if (empty($data['product_id'])) {
            $this->error = '请选择商品';
            return false;
        }
        
        // 获取商品信息
        $product = ProductModel::find($data['product_id']);
        if (!$product || $product['status'] != 1) {
            $this->error = '商品不存在或已下架';
            return false;
        }
        
        // 生成订单号
        $orderNo = $this->generateOrderNo();
        
        // 计算订单金额
        $amount = $product['price'] * ($data['quantity'] ?? 1);
        
        // 订单数据
        $orderData = [
            'order_no' => $orderNo,
            'user_id' => $userId,
            'product_id' => $product['id'],
            'expert_id' => $product['expert_id'],
            'title' => $product['title'],
            'amount' => $amount,
            'quantity' => $data['quantity'] ?? 1,
            'remark' => $data['remark'] ?? '',
            'status' => OrderModel::STATUS_PENDING_PAY,
            'created_at' => time(),
        ];
        
        // 创建订单
        $orderId = $this->repository->create($orderData);
        
        return [
            'order_id' => $orderId,
            'order_no' => $orderNo,
            'amount' => $amount,
        ];
    }
    
    /**
     * 生成订单号
     */
    protected function generateOrderNo(): string
    {
        return 'EG' . date('YmdHis') . mt_rand(1000, 9999);
    }
}
```

#### 5.1.3 仓储层（Repository）

仓储层负责数据访问的封装，提供统一的数据操作接口，将数据访问逻辑与业务逻辑分离，提高代码的可维护性。

```php
<?php

namespace app\repository;

use app\model\Order as OrderModel;

/**
 * 订单仓储层
 */
class OrderRepository
{
    /**
     * 创建订单
     */
    public function create(array $data): int
    {
        $model = new OrderModel();
        $model->save($data);
        return $model->id;
    }
    
    /**
     * 根据ID获取
     */
    public function findById(int $id): ?OrderModel
    {
        return OrderModel::find($id);
    }
    
    /**
     * 根据订单号获取
     */
    public function findByOrderNo(string $orderNo): ?OrderModel
    {
        return OrderModel::where('order_no', $orderNo)->find();
    }
    
    /**
     * 获取列表
     */
    public function getList(array $where = [], int $page = 1, int $limit = 15): array
    {
        $query = OrderModel::where(function($query) use ($where) {
            foreach ($where as $field => $value) {
                if ($value !== '' && $value !== null) {
                    if (is_array($value)) {
                        $query->where($field, $value[0], $value[1]);
                    } else {
                        $query->where($field, $value);
                    }
                }
            }
        });
        
        return $query->order('id desc')
            ->page($page, $limit)
            ->select()
            ->toArray();
    }
    
    /**
     * 获取数量
     */
    public function getCount(array $where = []): int
    {
        $query = OrderModel::where(function($query) use ($where) {
            foreach ($where as $field => $value) {
                if ($value !== '' && $value !== null) {
                    $query->where($field, $value);
                }
            }
        });
        
        return $query->count();
    }
}
```

### 5.2 分层依赖原则

三层架构的依赖关系应该遵循由上向下依赖的原则，控制器层依赖服务层，服务层依赖仓储层，仓储层依赖模型层，禁止出现反向依赖或跨层依赖的情况，在实际开发中应该注意保持各层之间的边界清晰，避免业务逻辑渗透到控制器层或数据访问逻辑渗透到服务层。

### 7.3 缓存更新策略

#### 7.3.1 Cache Aside模式

读操作流程为：首先查询缓存，如果缓存命中则直接返回缓存数据，如果缓存未命中则查询数据库，将数据写入缓存后返回；写操作流程为：首先更新数据库，删除对应的缓存数据，下次读取时再加载最新数据到缓存。

```php
<?php

/**
 * Cache Aside模式示例
 */
class UserService
{
    public function getUserInfo(int $userId): ?array
    {
        $cacheKey = "user:info:{$userId}";
        
        // 1. 查询缓存
        $cached = Redis::get($cacheKey);
        if ($cached) {
            return json_decode($cached, true);
        }
        
        // 2. 缓存未命中，查询数据库
        $user = UserModel::find($userId);
        if (!$user) {
            return null;
        }
        
        // 3. 写入缓存
        Redis::setex($cacheKey, 3600, json_encode($user));
        
        return $user;
    }
    
    public function updateUserInfo(int $userId, array $data): bool
    {
        // 1. 更新数据库
        $result = UserModel::where('id', $userId)->update($data);
        
        if ($result) {
            // 2. 删除缓存
            $cacheKey = "user:info:{$userId}";
            Redis::del($cacheKey);
        }
        
        return $result;
    }
}
```

```php
<?php

/**
 * 文件上传服务
 */
class UploadService
{
    protected string $bucket;
    protected string $domain;
    
    public function __construct()
    {
        $this->bucket = config('storage.oss.bucket');
        $this->domain = config('storage.oss.domain');
    }
    
    /**
     * 上传文件
     */
    public function upload(string $filePath, string $dir = 'default'): array
    {
        // 1. 生成文件名
        $extension = pathinfo($filePath, PATHINFO_EXTENSION);
        $filename = $this->generateFilename($extension);
        $object = "{$dir}/{$filename}";
        
        // 2. 上传到OSS
        $oss = new OssClient(
            config('storage.oss.access_key'),
            config('storage.oss.secret_key'),
            config('storage.oss.endpoint')
        );
        
        $oss->uploadFile($this->bucket, $object, $filePath);
        
        // 3. 返回访问URL
        $url = $this->domain . '/' . $object;
        
        return [
            'url' => $url,
            'path' => $object,
            'filename' => $filename,
        ];
    }
    
    /**
     * 生成文件名
     */
    protected function generateFilename(string $extension): string
    {
        return date('Ymd') . '/' . uniqid() . '.' . $extension;
    }
    
    /**
     * 删除文件
     */
    public function delete(string $object): bool
    {
        $oss = new OssClient(/* ... */);
        return $oss->deleteObject($this->bucket, $object);
    }
}
```

```yaml
version: '3.8'

services:
  # Nginx服务
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/nginx.conf
      - ./server:/var/www/html
    depends_on:
      - php
    networks:
      - app-network

  # PHP-FPM服务
  php:
    build:
      context: ./docker/php
      dockerfile: Dockerfile
    volumes:
      - ./server:/var/www/html
    depends_on:
      - mysql
      - redis
    networks:
      - app-network

  # MySQL服务
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: ${DB_PASSWORD}
      MYSQL_DATABASE: escort_game
    volumes:
      - mysql-data:/var/lib/mysql
      - ./scripts/init.sql:/docker-entrypoint-initdb.d/init.sql
    ports:
      - "3306:3306"
    networks:
      - app-network

  # Redis服务
  redis:
    image: redis:6-alpine
    volumes:
      - redis-data:/data
    ports:
      - "6379:6379"
    networks:
      - app-network

  # Workerman服务
  workerman:
    build:
      context: ./docker/php
      dockerfile: Dockerfile
    command: php /var/www/html/im/start.php start -d
    volumes:
      - ./server:/var/www/html
      - ./im:/var/www/html/im
    depends_on:
      - mysql
      - redis
    networks:
      - app-network

networks:
  app-network:
    driver: bridge
```
